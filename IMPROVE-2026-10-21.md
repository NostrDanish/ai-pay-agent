# Improvement Deep-Dive — ai-pay-agent — 2026-10-21

## Top recommendations (ranked, with effort S/M/L)
1. **Replace the `nostrwalletconnect` Python dependency** — unverified/unmaintained; since NIP-47's 2026-08 core simplification (PR #2419) the full core is just 5 methods over kind 23194/23195 + info kind 13194, so a ~150-line stdlib+websockets client is now realistic and removes the supply-chain risk entirely. Alternatively shell out to a pinned JS `@getalby/sdk`. [M]
2. **Add requirements.txt / pyproject** — no manifest exists, so the one dependency is unpinned and unnamed-versioned. [S]
3. **Implement or delete the NutZap fallback** — `pay_nutzap()` only prints; it never publishes kind:9321 (NIP-61). Half-features in a payment tool are dangerous (caller believes a payment happened). Either sign+publish the nutzap event or raise NotImplementedError. [S]
4. **Add NIP-A3 (payto:) support** — parse `payto:` URIs as a payment target alongside BOLT11 invoices; that's the 2026-standard way to request non-LN payment on Nostr and fits 'pay other AIs' perfectly. [M]
